# Urodziny Mamy

Statyczna kartka urodzinowa przygotowana do publikacji na GitHub Pages.

## Podgląd lokalny

Otwórz plik `index.html` w przeglądarce. Strona nie wymaga instalowania Node.js ani żadnych zależności.

## Publikacja

1. Wyślij całą zawartość tego katalogu do publicznego repozytorium GitHub.
2. W repozytorium otwórz `Settings` → `Pages`.
3. W `Build and deployment` ustaw `Source` na `GitHub Actions`.
4. Otwórz zakładkę `Actions` i poczekaj na zakończenie zadania `Deploy GitHub Pages`.

Nie usuwaj katalogu `.github` — zawiera konfigurację automatycznej publikacji.
